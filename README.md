# For Anika · Happy Birthday

A handcrafted, mobile-first birthday universe built for one person only: **Anika (04 / 10 / 2008)**.

## The journey
1. **The lock**: a keypad that only opens for her date: `04/10/2008` (DD/MM/YYYY, MM/DD/YYYY also accepted).
2. **The first letter**: a wax-sealed airmail envelope that cracks open and unfolds.
3. **The scrapbook**: polaroids, a fold-out note, and a jar of wishes to tap.
4. **The cake**: blow the candles by tap, by button, or with a real breath into the microphone.
5. **The final letter**: arrives on its own the moment the candles go out.

Every sound (keypad clicks, wax cracks, the music box) is synthesized live with the Web Audio API. No external audio files. Only Google Fonts loads from the network.
